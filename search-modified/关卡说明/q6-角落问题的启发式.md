#### 启发函数的基本要求

启发函数是 `A*` 搜索算法中用于估计从当前状态到目标的最小剩余代价的函数。在数学上，对于任意状态 $$n$$ 和目标状态 $$n_{\text{goal}}$$，启发函数 $$h(n)$$ 应满足：
```latex
0 \le h(n) \le h^*(n)
```

其中 $$ h^*(n) $$  表示从 $$n$$ 到目标状态的实际最短路径代价。也就是说，启发函数的返回值必须非负，在目标状态时应返回 `0`，以保证算法能够正确判断搜索完成。进一步，为保证一致性，对任意节点 $$n$$ 及其子节点 $$n'$$ 及动作代价 $$c(n, n')$$ 必须满足：

```latex
h(n) \le c(n, n') + h(n')
```

在项目中，这对应于 `cornersHeuristic` 中的实现逻辑：启发函数通过累加从当前位置到剩余未访问角落的曼哈顿距离来估计总代价，从而保证不会高估真实路径：

```
# 当所有角落已访问时，启发函数返回 0
if len(next_corners) == 0:
    return 0
```

同时，每次累加距离都基于最小距离选择，使启发函数在搜索中始终提供低估值，从而保持可采纳性和一致性。



#### 曼哈顿距离

曼哈顿距离用于估计网格地图上两点之间沿水平和垂直方向移动的最短步数。数学定义为：
```latex
\text{ManhattanDistance}((x_1, y_1), (x_2, y_2)) = |x_1 - x_2| + |y_1 - y_2|
```
在启发函数中，它提供了一个简单且可采纳的下界估计。例如，在四角访问问题中，从当前位置到某个未访问角落的曼哈顿距离可直接用于贪心选择最近角落：

```
# 计算当前位置到所有未访问角落的曼哈顿距离
distances = [manhattanDistance(current_state, corner) for corner in next_corners]

# 贪心选择最近角落
min_dist = min(distances)
h_n += min_dist
```

该方法对应数学中的 $$\min_{c \in \text{未访问角落}} \text{ManhattanDistance}(s, c)$$，保证启发函数不会高估真实代价，同时为 `A*` 搜索提供方向性，引导搜索优先向剩余角落集中扩展。


#### 最小生成树

在多目标问题中，仅使用当前位置到最近目标的距离往往低估总代价。为更准确地估计访问所有剩余目标的最小总代价，可以借鉴最小生成树（`Minimum Spanning Tree`, `MST`）的思想。设剩余未访问目标集合为 $$R = \{c_1, c_2, \dots, c_k\}$$，则 `MST` 估计代价可表示为：
```latex
h_{\text{MST}}(s) = \min_{c \in R} \text{ManhattanDistance}(s, c) + \text{MST\_cost}(R)
```
其中，`$$\text{MST\_cost}(R)$$` 表示连接所有未访问角落的最小边权和。在项目中，可以通过**贪心方法**近似 `MST`：每次选择离当前位置最近的未访问角落，并累加距离，直到所有角落都被考虑：

```
while len(next_corners) > 0:
    distances = [manhattanDistance(current_state, corner) for corner in next_corners]
    min_dist = min(distances)
    min_index = distances.index(min_dist)
    h_n += min_dist
    current_state = next_corners[min_index]
    del next_corners[min_index]
```

这种方法虽然是近似 `MST`，但保证了启发函数仍然是可采纳的下界估计，同时在多目标场景下提供合理的总代价估计，使 `A*` 搜索高效。
