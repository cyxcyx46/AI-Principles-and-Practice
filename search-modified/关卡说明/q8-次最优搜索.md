### 任务描述


本关任务：采用贪心策略让每一步都寻找并吃掉当前最近的食物，通过不断解决“最近食物”的子问题，完成整张地图的食物清除任务。


### 相关知识


为了完成本关任务，你需要掌握：

1. 贪心策略；

2. 子最优搜索；

3. 问题分解。

#### 贪心策略
贪心策略的核心思想是在每一步决策时，优先选择当前看来代价最小、收益最大的行动，而不对未来所有可能情况进行穷举分析。在项目中，该思想体现在：**每一次只寻找并前往当前最近的一个食物点**，而不试图一次性规划吃完所有食物的全局路径。

在代码中，这一策略通过 `findPathToClosestDot` 函数实现。函数首先根据当前 `gameState` 构造一个 `AnyFoodSearchProblem`，然后直接调用搜索算法：

```python
problem = AnyFoodSearchProblem(gameState)
return search.aStarSearch(problem)
```

这里的搜索目标并非“吃完所有食物”，而是“到达任意一个食物点”。这种做法使得每一次搜索都只关注当前最近的目标，体现了典型的局部最优选择特征。虽然贪心策略无法保证全局最优解，但在迷宫规模较大、食物数量较多的情况下，能够显著降低搜索复杂度，提高运行效率。

#### 子最优搜索

子最优搜索是指将一个全局最优问题拆解为若干个可以高效求解的子问题，并通过连续求解这些子问题来完成整体任务。在吃豆问题中，“吃完所有食物”是一个高维状态空间问题，而“从当前位置到最近的一个食物”则是一个规模较小的最短路径问题。

这一思想在 `AnyFoodSearchProblem` 的目标判定函数中得到了直接体现：

```
def isGoalState(self, state):
    x, y = state
    foodGrid = self.food
    if foodGrid[x][y] == True:
        return True
    else:
        return False
```

该函数将**任意包含食物的位置**视为目标状态，从而把原问题转化为“到某个食物”的子问题。搜索算法在第一次到达某个食物位置时即可终止，返回一条最短路径。每解决一个子问题，就减少一个食物点，状态空间随之缩小，使后续搜索更加高效。


#### 问题分解

问题分解是指将一个复杂目标分解为多个结构相同、可重复求解的简单问题。在本项目中，“清除整张地图上的所有食物”被分解为一系列“到最近食物并吃掉它”的独立子任务。

在代码层面，这种分解体现在以下流程中：

1. 当前状态下构造 `AnyFoodSearchProblem`；
2. 使用搜索算法求解到最近食物的路径；
3. 执行返回的动作序列，吃掉该食物；
4. 以新的状态重复上述过程，直到食物清空。

由于 `AnyFoodSearchProblem` 继承自 `PositionSearchProblem`，其状态空间和后继函数无需修改，只需改变目标测试条件即可完成问题分解。这种设计不仅降低了实现难度，还保证了每个子问题都可以复用已有的搜索算法。
