### 任务描述

本关卡的核心任务是于 `multiAgents.py` 文件中设计并实现一个高鲁棒性的评估函数（`betterEvaluationFunction`）。

在前序关卡中，我们构建了基于 `Alpha-Beta` 剪枝与 `Expectimax` 的对抗搜索智能体，赋予了 `Pacman` 强大的前瞻推演能力。然而，受限于计算资源与实时性要求，搜索树必须在特定深度（`depth == 0`）截断。此时，AI 无法继续通过推演获知胜负，必须依赖评估函数对当前叶子节点的静态局面进行精准量化。本关要求提取游戏状态中的多维战术特征，通过线性加权组合构建终极评估模型，使 `Pacman` 在缺乏深层搜索支持的情况下，依然能够表现出高效的觅食、避险与猎捕行为。

### 相关知识

为了完成本关任务，你需要掌握：1. 状态评估与动作评估的范式差异；2. 线性特征组合的数学模型；3. 终极`Pacman` 特征提取。

#### 状态评估与动作评估的范式差异

在第一关（反射型智能体）中，我们实现的是动作评估（`Action Evaluation`），其对象是“当前状态执行某动作后的瞬时后继状态”，适用于无搜索树的贪婪策略。而在本关中，我们需要实现的是状态评估（`State Evaluation`）。该函数直接面向静态的 `currentGameState` 进行价值度量，不依赖于“如何到达该状态”的历史路径信息。该函数的输出值将作为搜索算法（`Minimax / Expectimax`）在递归触底时的效用值（`Utility Value`），直接决定了搜索树根节点的决策走向。

#### 线性特征组合的数学模型
为了将复杂的博弈盘面转化为可比较的标量数值，AI 领域通用的方法是建立线性特征组合模型（`Linear Feature Combination`）。该模型提取状态中客观存在的特征（`Features`,$$f$$）并赋予对应的主观权重（`Weights`,$$w$$），通过线性加权求和得出最终评分：$$ Eval(s) = w_1 f_1(s) + w_2 f_2(s) + ... + w_n f_n(s) $$

在此模型中，特征($$f$$)反映当前局面的客观指标，如“最近食物距离”、“剩余能量胶囊数量”等。权重($$w$$)反映策略倾向的超参数。正权重代表正向激励（`Reward`），负权重代表惩罚（`Penalty`）。权重的绝对值大小决定了该特征在决策逻辑中的优先级。

#### 终极`Pacman` 特征提取

结合本实验的代码框架与博弈规则，一个完备的评估函数应当包含以下四个维度的领域知识特征：

1. 游戏基底（`Game Score`）：直接复用游戏引擎提供的 `score` 属性。该分数内置了“吞食食物加分”与“随时间流逝扣分”的基础规则，是评估函数最底层的基石（权重通常设为 1）。

2. 觅食启发势（`Foraging Heuristics`）：距离因子，采用最近食物距离的倒数形式（如`1 / (dist + 1)`，加 1 用于防止除零异常）作为激励项，引导智能体向食物逼近；全局数量惩罚，剩余食物总数越少意味着越接近胜利，因此需对 `len(Food)` 施加负权重，迫使智能体以全局清空食物为目标。

3. 对抗生存势（`Adversarial Heuristics`）：避险模式（幽灵未受惊），当幽灵处于正常状态时，距离是生死的关键。若距离极近（如 $$< 2$$），触发死亡判定，必须给予极大的负值惩罚（如 -500）以实现“一票否决”；若处于警戒范围（如$$< 4$$），则施加基于距离倒数的中等惩罚；猎捕模式，当幽灵处于受惊状态（`scaredTimer > 0`）时，它们转变为高价值的奖励目标。此时应翻转策略，距离越近给予的正向奖励越高，鼓励 `Pacman` 主动出击。

4. 战略资源势（`Strategic Resources`）：能量胶囊是扭转攻守态势的关键道具。若智能体周边（如距离 $$< 5$$）存在胶囊，应给予强烈的距离倒数奖励，诱导 Pacman 优先获取战术优势。

### 编程要求

请在 `multiAgents.py` 文件中` betterEvaluationFunction` 函数体内（即 `BEGIN-END `之间），基于上述战术逻辑实现特征提取与加权计算。具体实施步骤如下：

1. **数据解包与初始化**：
    - 从 `currentGameState` 中提取核心状态数据：`Pacman` 坐标、食物分布列表、幽灵状态集及能量胶囊列表。
    - 初始化评估总分 `score`，直接赋值为当前游戏的基础得分 `currentGameState.getScore()`。

2. **计算觅食特征权重**：
    - 若食物列表非空，计算 `Pacman` 至最近食物的曼哈顿距离 minFoodDist。
    - 累加距离激励：向 `score` 增加 `10.0 / (minFoodDist + 1)`。
    - 累加数量惩罚：向 `score` 扣除 `4 * len(Food)`，以强化全局清盘动机。

3. **计算对抗特征权重**：
    - 遍历每一个幽灵的状态，获取其与 `Pacman` 的距离 `dist` 及受惊倒计时 `scaredTimer`。
    - 猎捕分支：若 `scaredTimer > 0`，表明幽灵可被捕食，累加追捕奖励 `(10 - dist) * 2`。
    - 避险分支：若幽灵处于正常威胁状态，检测距离阈值。若 `dist < 2`（濒死），扣除巨额惩罚 `500`；若` dist < 4`（警戒），扣除中额惩罚 `50 / (dist + 1)`。

4. **计算战略资源权重**：
    - 若能量胶囊列表非空，计算至最近胶囊的距离 `minCapsuleDist`。
    - 若 `minCapsuleDist < 5`，累加资源诱导奖励 `5.0 / (minCapsuleDist + 1)`。

5. **返回结果**：返回最终计算所得的 `score` 作为该状态的静态效用值。
